Every repository you own, in one tidy workspace.

Corral clones and organises GitHub repositories into Finder-friendly collections, grouped by visibility, ecosystem, and metadata. One Go binary, corralctl.

Install Documentation GitHub

Install

macOS and Linux. Managed alongside the rest of your tools.

mise use -g github:sebastienrousseau/corral

Also available via Homebrew (brew install sebastienrousseau/tap/corralctl), the AUR (corralctl-bin), .deb/.rpm packages, or built from source with Go 1.26+.

One command

Fetches everything you own and lays it out predictably.

corralctl <your-github-username>

Repositories land in a structure you can navigate without thinking:

~/Code
├── Public
│   ├── Go        corral, …
│   ├── Rust      …
│   └── Python    …
└── Private
    └── JavaScript …

What it does

Built for people whose repository count outgrew their patience.

Structured layout

Collections and ecosystems derived from each repository's visibility and primary language, with customisable templates.

Smart syncing

Network-optimised incremental updates that skip work when nothing upstream has changed.

Concurrent by default

Clone and refresh many repositories at once, with the concurrency under your control.

Interactive TUI

A terminal interface with keybindings, commands, and autocomplete for browsing the workspace.

Exec mode

Run a Git command across every repository in the workspace, concurrently.

MCP server

Expose the workspace to AI coding agents over the Model Context Protocol, built on the official Go SDK.
